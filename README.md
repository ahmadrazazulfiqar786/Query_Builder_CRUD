# Query Builder CRUD API (Laravel)

A professional RESTful API built with **Laravel**, using **Query Builder (no Eloquent for Product CRUD)**, **Repository Pattern**, **Laravel Passport Authentication**, and **Swagger Documentation**.

This project demonstrates a clean backend API architecture suitable for production-ready Laravel applications.

---

# Project Features

## Authentication APIs (Laravel Passport)

* Register user
* Login user
* Logout user
* OAuth2 token-based authentication

---

## Product CRUD APIs (Query Builder Only)

Implemented using **Laravel Query Builder instead of Eloquent**

Endpoints:

* Create product
* Get all products
* Get single product
* Update product
* Delete product

---

# Technologies Used

* Laravel
* PHP 8+
* Query Builder (DB::table)
* Repository Pattern
* Form Request Validation
* Laravel Passport (OAuth2)
* Swagger (L5-Swagger)
* SQLite / MySQL supported

---
